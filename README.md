# Tri3fluent — Landing Page para Profissional de Inglês

## Visão geral

Este projeto nasceu de um freela como desenvolvedor front-end: criar uma landing page moderna, acolhedora e conversacional para a professora de inglês Lígia, idealizadora da marca Tri3fluent.

A proposta era transformar a identidade da professora em uma presença digital elegante, funcional e persuasiva, com foco na conversão de visitantes em alunos. O resultado foi uma página voltada para pessoas que querem aprender inglês com mais confiança, sem pressão e com um ambiente acolhedor.

A ideia central da marca era simples e poderosa: aprender inglês não precisa ser algo distante, rígido ou intimidador. A comunicação visual foi pensada para transmitir acolhimento, leveza, sofisticação e confiança — elementos essenciais para a proposta da professora.

---

## O que foi desenvolvido

A landing page foi estruturada para contar uma história clara e objetiva:

- apresentar a professora e sua proposta de ensino
- reforçar a ideia de que o aprendizado é personalizado e acessível
- destacar os benefícios da metodologia
- mostrar depoimentos e reforçar acredibilidade
- direcionar o usuário para uma ação clara: agendar aula experimental ou falar no WhatsApp

Além disso, o layout foi pensado para funcionar como uma máquina de conversão, combinando bom design visual com comunicação estratégica.

---

## Objetivo do projeto

O principal objetivo era criar uma página que:

- transmitisse confiança desde o primeiro clique
- valorizasse a marca pessoal da professora
- destacasse a proposta de inglês para mulheres com foco em conversação
- gerasse contato direto por WhatsApp
- entregasse uma experiência visual refinada em desktop e mobile

Em termos práticos, foi um projeto de front-end com foco em experiência do usuário, branding, persuasão visual e marketing digital.

## Conceitos práticos aplicados

### 1. HTML semântico

A estrutura da página foi organizada com elementos como:

- `header` para o topo da navegação
- `nav` para o menu principal
- `main` para o conteúdo principal
- `section` para separar blocos de informação
- `article` para os cards de benefícios e metodologia
- `footer` para fechamento do site

Esse tipo de estrutura melhora a legibilidade do código, facilita manutenção e torna a página mais acessível para tecnologias assistivas.

### 2. Hierarquia visual

A página foi pensada para guiar o olhar do usuário de forma natural:

- primeiro a mensagem principal da hero
- depois os diferenciais
- depois a apresentação da professora
- em seguida a metodologia
- e por fim a ação de conversão

Isso é essencial para transformar uma página bonita em uma página com objetivo comercial.

### 3. Design system simples e elegante

O projeto usa uma paleta de cores suaves e sofisticadas, combinando tons de nude, lilás, bege, terracota e azul petróleo. A identidade visual foi escolhida para transmitir:

- acolhimento
- feminilidade
- seriedade profissional
- leveza emocional

Além disso, a tipografia foi tratada com cuidado: títulos em fonte serifada para um tom mais elegante e textos em fonte sans-serif para leitura confortável.

### 4. CSS custom properties

A manutenção visual ficou mais organizada usando variáveis no CSS, como:

- cores
- sombras
- bordas
- tamanhos de texto
- contrastes

Isso permite uma evolução mais fácil do design sem precisar refazer várias partes do código manualmente.

### 5. Flexbox e Grid

O layout foi construído com técnicas modernas de posicionamento:

- `Flexbox` para alinhamento de navegação, botões e áreas internas
- `Grid` para composição de blocos maiores e organização visual da estrutura

Esses recursos ajudam a criar layouts limpos, responsivos e bem distribuídos.

### 6. Responsividade mobile-first

A landing page foi planejada para funcionar bem em diferentes telas. Em celulares, os elementos são empilhados de forma clara e amigável; em desktops, o conteúdo se expande em colunas e aproveita melhor o espaço disponível.

A responsividade é um conceito fundamental tanto para UX quanto para conversão, já que a maioria dos acessos hoje vêm de dispositivos móveis.

### 7. Microinterações e UX

A página possui botões com hover e transitions suaves, além de navegação mais fluida entre seções. Isso gera uma sensação de profissionalismo e melhora a experiência do usuário sem exagerar em elementos visuais.

Detalhes como:

- elevação ao passar o mouse
- linha animada em menu
- sombras suaves
- suavização de scroll

fazem toda a diferença na percepção de qualidade da marca.

### 8. Acessibilidade web

Mesmo sendo um projeto visualmente refinado, houve atenção a acessibilidade:

- textos alternativos em imagens (`alt`)
- uso adequado de semântica
- foco visível em links e ações
- contraste pensado entre texto e fundo
- navegação fluida por teclado

Isso mostra que um bom front-end não trata design e acessibilidade como coisas separadas — elas andam juntas.

### 9. Cópia e persuasão

Uma landing page bem feita não depende só de código; ela depende também de mensagem. O texto foi desenhado para falar diretamente com o público-alvo:

- acolher
- mostrar que o aprendizado é possível
- reduzir a insegurança
- reforçar confiança
- incentivar a ação

Os textos do site reforçam a proposta da professora de um jeito natural e humano.

### 10. Conversão e CTA

A ação principal da página foi pensada como uma conversão direta para WhatsApp. Isso é bastante comum em negócios pessoais e profissionais, porque transforma o visitante em lead com o menor atrito possível.

Elementos como:

- botão de agendar aula experimental
- botão de contato direto
- CTA em blocos estratégicos

são exemplos de como o front-end também trabalha com objetivos de negócio.

### 11. Branding pessoal

Este projeto foi muito mais do que um site “bonitinho”. Foi uma peça de branding pessoal para a professora. A identidade construída transmite uma presença online profissional e emocionalmente conectada com o público.

Isso é essencial quando o cliente é um profissional autônomo ou especialista: o site deve vender a pessoa, a proposta e a confiança, não só os serviços.

### 12. Organização e manutenção

A estrutura simples do projeto mostra uma boa prática de organização:

- HTML separado do CSS
- recursos em pastas específicas
- imagens bem nomeadas
- foco em reutilização visual

Isso facilita futuras alterações, novas seções ou adaptações para campanhas específicas.
